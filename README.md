# AI Outfit Recommender

A modern, AI-powered outfit recommendation platform with 3D visualization.

## Project Structure

- `web/`: The Next.js frontend application.

## Getting Started

1. Navigate to the web directory:
   ```bash
   cd web
   ```

2. Install dependencies (if you haven't already):
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Features

- **Home Page**: 3D interactive preview and quick actions.
- **Upload**: Drag & drop clothing upload with simulated AI generation.
- **Wardrobe**: Manage your digital closet.
- **Settings**: Theme toggle and preferences.
